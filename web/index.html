تثبيت برنامج ESP8266

لوحة NodeMCU ESP8266 بذاكرة 4MB. وصّلها بكابل USB ثم اضغط الزر.

  1. استخدم Chrome أو Edge على الكمبيوتر.
  2. أغلق أي برنامج يستعمل منفذ اللوحة.
  3. اضغط Install واختر منفذ USB الخاص باللوحة.

بعد التثبيت اتصل بشبكة ESP8266-Test-AP بكلمة المرور ChangeMe8266، ثم افتح http://192.168.4.1.

هذا البرنامج يدير فقط الأجهزة المتصلة بنقطة الوصول الخاصة باللوحة، ولا يستهدف شبكات خارجية.
